# minigame 2
## Devlog
One issue I ran into while writing my code was that I forgot to put float in front of 'r'. This caused an error because it didn't recognize r as a variable since I hadn't declared it or told the program what type of value it was supposed to hold. I fixed the small issue by adding float before r so C# would know that r was a variable that could store a decimal number

It's for changing the color of the sprite. 'r' controls the red part of the color, while the two 0.2f values control the green and blue. period (.) is used to access something that belongs to another thing, like the color of the sprite renderer. I think new just means the code is making a new color with those values
